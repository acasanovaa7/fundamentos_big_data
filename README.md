# 📊 Fundamentos de Big Data

Repositorio dedicado al estudio, práctica e implementación de los conceptos fundamentales del procesamiento masivo de datos (*Big Data*). Contiene notas teóricas, laboratorios, ejercicios prácticos y proyectos orientados al almacenamiento y análisis distribuido.

---

## 🚀 Contenidos del Repositorio

* **Introducción a Big Data:** Las Vs del Big Data, arquitecturas tradicionales vs. distribuidas.
* **Almacenamiento Distribuido (HDFS):** Operaciones, comandos de consola y arquitectura de Hadoop.
* **Procesamiento de Datos:**
  * **MapReduce:** Paradigma de programación distribuida y casos de uso.
  * **Apache Spark / PySpark:** Procesamiento en memoria con DataFrames, RDDs y Spark SQL.
* **Bases de Datos NoSQL:** Modelado clave-valor, documental y orientado a columnas.
* **Proyectos Prácticos:** Implementación de canalizaciones (*pipelines*) de análisis de datos.

## 📋 Requisitos Previos

Antes de ejecutar los *notebooks* o scripts, asegúrate de contar con:

* [Python 3.8+](https://www.python.org/)
* [Apache Spark](https://spark.apache.org/) (con PySpark instalado)
* [Docker](https://www.docker.com/) (opcional, para entornos de Hadoop/Spark local)
